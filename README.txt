UPLOAD INSTRUCTIONS
1. Extract this ZIP on your computer.
2. Open the extracted khushi-memory-website folder.
3. Upload the CONTENTS of that folder to the ROOT of your new GitHub repository.
4. Make sure the entire assets folder is uploaded, not just the files beside it.
5. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.

Do not rename the image files or move them out of assets/photos.
